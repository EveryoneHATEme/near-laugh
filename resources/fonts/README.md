at commit `ffebf8c1ee449e544955a7e813c54f9b73848eac`, path
`hinted/ttf/NotoSans/NotoSans-Regular.ttf`. The unmodified font is distributed
under the [SIL Open Font License](OFL.txt), copied from that revision.

SHA-256:

- NotoSans-Regular.ttf: `b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5`
- OFL.txt: `0dab92d0544f7b233403f14b84a663bdbfa746982eda629e7f4f9ffe1b036feb`

Only this trusted font is accepted by game text preparation. Font parsing must
follow content-hash verification. Latin, Russian Cyrillic including Ё/ё,
digits and punctuation are the intended caption repertoire.
